Caracteristicas:
  - Proporcionam a redução de código repetitivo.
  - PHP suporta várias estruturas de repetição, como for, while, do-while e foreach.
  - Cada estrutura de repetição tem sua própria sintaxe e uso específico.
  - Permitem iterar sobre arrays e objetos de forma eficiente.
  - Podem ser combinadas com estruturas de decisão para criar fluxos de controle complexos.
  - Facilitam a manipulação de grandes conjuntos de dados.

while em PHP:
  - Sintaxe:
      ```php
      while (condição) {
          // código a ser executado enquanto a condição for verdadeira
      }
      ```
  - Exemplo:
      ```php
      $contador = 0;
      while ($contador < 5) {
          echo "Contador: $contador\n";
          $contador++;
      }
      ```
  - Sintaxe alternativa:
      ```php
      while (condição):
          // código a ser executado enquanto a condição for verdadeira
      endwhile;
      ```

do-while em PHP:
  - Sintaxe:
      ```php
      do {
          // código a ser executado
      } while (condição);
      ```
  - Exemplo:
      ```php
      $contador = 0;
      do {
          echo "Contador: $contador\n";
          $contador++;
      } while ($contador < 5);
      ```
  - Diferença principal: o bloco de código é executado pelo menos uma vez, mesmo que a condição seja falsa.

for em PHP:
  - Sintaxe:
      ```php
      for (inicialização; condição; incremento) {
          // código a ser executado
      }
      ```
  - Exemplo:
      ```php
      for ($i = 0; $i < 5; $i++) {
          echo "Índice: $i\n";
      }
      ```

foreach em PHP:
  - Sintaxe:
      ```php
      foreach ($array as $valor) {
          // código a ser executado para cada valor
      }
      ```
  - Exemplo:
      ```php
      $frutas = ["maçã", "banana", "laranja"];
      foreach ($frutas as $fruta) {
          echo "Fruta: $fruta\n";
      }
      ```

  foreach é especialmente útil para iterar sobre arrays e objetos, simplificando o código e melhorando a legibilidade.
